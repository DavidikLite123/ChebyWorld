# ChebyWorld — Minecraft сервер

Официальный сайт-лендинг сервера **ChebyWorld**: о сервере, донаты и привилегии, правила, контакты.

Сайт — это один статический HTML-файл [`index.html`](./index.html) (стили и скрипты встроены, внешние ресурсы — только Google Fonts). Никакой сборки не требуется.

## Деплой на Vercel

1. Загрузите репозиторий на GitHub (или используйте уже существующий: `DavidikLite123/ChebyWorld`).
2. Откройте [vercel.com/new](https://vercel.com/new) и импортируйте этот репозиторий.
3. Нажмите **Deploy** — настройки менять не нужно:
   - Framework Preset: **Other** (определится автоматически)
   - Build Command: пусто
   - Output Directory: пусто (корень репозитория)

Vercel автоматически отдаст `index.html` по корневому адресу. После деплоя можно привязать свой домен в **Settings → Domains**.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический сервер, например:

```bash
npx serve .
# или
python3 -m http.server 8000
```
